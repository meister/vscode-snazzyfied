## How to contribute

1. Fork and clone this repo. `git clone https://github.com/<YOUR-USERNAME>/vscode-snazzyfied`
2. Create a branch for your changes. `git checkout -b my-new-feature`
3. Install dependencies. `npm install`
4. Open the `vscode-snazzyfied` folder in VS Code.
5. Make your changes
6. Build and examine your changes in an Extension Development Host
  * _Debug_ > _Start Debugging_ or use `F5` as a shortcut
7. You can test the theme locally, by running `npm run build` in the terminal
  * This should create `theme-snazzyfied-*.vsix` file which can be installed inside VS Code command palette (Palette > _Extensions: Install from VSIX..._)
8. Commit and push your changes
9. Submit a PR for discussion, however if some suggestions conflict the original ideas, they may be rejected
